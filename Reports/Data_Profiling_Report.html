Important Structural Limitations

  • 236 of 5,000 orders have no Order_Items records.
  • SupplierID appears only in Suppliers, so supplier performance cannot be linked to operational outcomes.
  • Warehouse capacity is not supplied; utilisation is represented only through labelled proxies.
  • Inventory has no date; repeated Warehouse-Product rows are treated as movements and aggregated only for reporting.
  • Returns identify OrderID but no ProductID/OrderItemID, so true product return rates cannot be computed.
  • Data dictionary is dataset-level only.
